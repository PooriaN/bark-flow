BARK FLOW

INSTALL
1. Drag Bark Flow to Applications. Open it from Applications.
2. If macOS blocks this build, it is ad hoc signed and not notarized. If you trust the source, try opening it once, then go to System Settings > Privacy & Security and choose Open Anyway. Apple explains this process at https://support.apple.com/102445.
3. Wait for the model to prepare. On first use this may take several minutes.
4. Allow microphone access. For automatic insertion, select Enable in the app and allow Bark Flow in System Settings > Privacy & Security > Device Control and Data Access (or Accessibility on older macOS).

USE
Place the cursor in a text field. Press Option + Space to start, then Option + Return to stop and transcribe. You can also stop in the floating listening window. In Settings, change shortcuts, theme and recording limit. Defaults apply to a fresh installation.

The app stays in the menu bar after its window is closed. Open it from the waveform icon. It requires an Apple silicon Mac with macOS 15 or newer. Recognition is local and currently English only.

MODELS
Plus is included. Selecting Bark 3.0 or Pro downloads the model from Hugging Face on first use, about 200 MB or 1.25 GB, respectively. Allow extra free disk space for model preparation. The models remain on your Mac after download. No audio is sent to Hugging Face.
